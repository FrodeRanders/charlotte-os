    \section*{Scope and status}
    This manual describes both the implemented CharlotteOS prototype and its
    intended architecture. Unless a section explicitly says otherwise,
    statements about security, performance, transport independence, hardware
    support, or failure recovery are design goals rather than production
    guarantees. The implementation-status appendix records the repository's
    currently verified scope; source code and tests remain authoritative when
    the manual and implementation differ.
